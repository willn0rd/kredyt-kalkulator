# kredyt-kalkulator

## Objective
This project was made to give you a perspective about mortgage, it does not require any data from the user.

## Scope
It compares current (at the moment of creation) interests from a few most popular banks in Poland.

## Notes
You can find the CLI app in folder called kredyt. 

## Disclaimer
It should not be your only tool when comparing offers, it was meant to give you a rough perspective without collecting any of your data.
